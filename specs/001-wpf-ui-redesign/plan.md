# Implementation Plan: WPF UI Redesign — Premium Gaming Interface

**Branch**: `001-wpf-ui-redesign` | **Date**: 2026-08-14 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-wpf-ui-redesign/spec.md`

## Summary

Redesign RouteXia's WPF client UI into a production-grade gaming utility with a codified dark
design system (color tokens, typography scale, 8px spacing grid), real-time latency graph
(Canvas/Polyline, 120-sample ring buffer per relay route), 5-state connection status machine
(`Disconnected → Connecting → Connected → Optimizing → KillSwitchActive`), automatic game
detection indicator (profile-sourced display name, no hardcoding), subscription/account widget
in sidebar footer, and relay region preference management in Settings.

All changes are additive or replacements within the existing `RouteXia.App` WPF project. No new
project or package is required.

## Technical Context

**Language/Version**: C# 12 / .NET 8 (WPF target framework: `net8.0-windows`)

**Primary Dependencies**:
- Lepo.WPF.UI (`wpfui`) — existing; `FluentWindow`, `SymbolIcon`, `ToggleSwitch`
- No new NuGet packages — latency graph is custom Canvas/Polyline (see research.md Decision 1)

**Storage**: App settings persisted via existing `System.Text.Json` serialization to local app
data folder; relay region preferences use same mechanism as existing settings.

**Testing**: Manual validation per `quickstart.md` (VS-001 through VS-008); automated tests are
out of scope for UI XAML layer.

**Target Platform**: Windows 10/11, x64, minimum 1080×680 display.

**Project Type**: Desktop application (WPF)

**Performance Goals**:
- Graph renders new data within 600ms of measurement (500ms poll + 100ms render budget)
- Hover transitions complete within 150ms
- UI thread CPU < 2% during active routing

**Constraints**:
- Constitution Principle VII: WPF/.NET only — no new UI frameworks
- Constitution Principle VI: No game name/process hardcoded in view or viewmodel layer
- Minimum window size: 1080×680 (existing `MainWindow.xaml` constraint)
- All colors must reference `ResourceDictionary` tokens (SC-006)

**Scale/Scope**: 11 files modified or created in `RouteXia.App`; 2 ViewModel extensions;
1 new `SpacingTokens.xaml`; 5 named typography styles added.
